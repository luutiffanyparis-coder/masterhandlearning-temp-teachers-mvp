# MasterHand Learning - Temporary Teacher Matching MVP

This repository contains a clickable front-end prototype for a tutoring company matching platform.

## Features included
- Teacher application form
- Student request form
- Matching engine with hard filters + scoring
- Teacher repository / approved profiles page
- Admin review area to approve submitted teachers
- Available times grouped into morning / afternoon / evening

## Stack
- React
- Vite
- CSS

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Overview
The MVP simulates a teacher recruitment and matching system for MasterHand Learning.
It is designed to help you test the workflow before building a full production backend.

## Notes
This is a front-end prototype only. Matching is done in the browser using demo data.
